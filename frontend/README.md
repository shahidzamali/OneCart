# OneCart – E-Commerce Website

OneCart is a full-featured e-commerce web application designed to provide a smooth online shopping experience with modern UI and secure backend services.

## 🚀 Features

- User authentication (Login / Signup)
- Product listing and search
- Shopping cart & checkout system
- Order management
- Responsive and mobile-friendly design
- Secure backend APIs

## 🛠️ Tech Stack

**Frontend:** React.js (Vite), HTML, CSS, JavaScript  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Styling:** CSS / Bootstrap  

## 📂 Project Highlights

- Developed scalable REST APIs using Node.js & Express  
- Integrated MongoDB for secure and efficient data storage  
- Designed responsive UI for better user experience  
- Implemented complete shopping workflow from browsing to checkout
